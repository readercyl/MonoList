# MonoList v0.11.1

本版本修复待办输入、长文本布局和提醒行为问题，不改变现有数据格式。

## 输入与编辑

- 输入框不再被 macOS 自动文本替换改写，保留用户输入的标点字符。
- 新增待办的输入框按真实内容高度增长，三行以上文本不会造成复选框错位。
- 编辑已有待办时可以用鼠标重新定位光标，点击输入框不会意外结束编辑。

## 提醒与专注

- 已设置单条定时提醒的任务不再参与短期轻提醒。
- 普通轻提醒和专注轻提醒显示 3 秒后自动消失，声音保持只响一声。
- 单条定时提醒显示 3 秒，提醒声音改为响三声。
- 专注轻提醒弹窗高度按任务内容自适应。

## 兼容性

本版本不改变待办、今日专注或现有设置的数据格式。兼容 macOS 14.0 及以上版本，普通升级不会清除用户数据。
