# MonoList v0.12.3

本版本调整子任务完成后的归组方式，并让菜单栏数量反映实际需要处理的事项。

## 更新内容

- 已完成子任务立即移入已完成区域，不再堆在待办父任务下；父子关系和各自完成时间继续保留。
- 最后一个子任务完成时，父任务同步完成，父子任务在已完成区域重新归组。
- 菜单栏只统计未完成子任务和没有子任务的独立任务，避免父子任务重复计数。
- 恢复已完成子任务时同步恢复父任务，计数和两个清单视图保持一致。

## 兼容性

- 支持 Apple 芯片 Mac（M1 或后续型号）。
- 支持 macOS 14.0 及以上版本。
- 不改变待办、完成记录、提醒设置或本地数据格式。
