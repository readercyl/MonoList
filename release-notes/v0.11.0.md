# MonoList v0.11.0

本版本新增自动更新，并修复轻提醒和菜单栏专注数量的一致性问题。

## 自动更新

- 升级到本版本后，MonoList 会每日自动检测新版本，验证更新包后自动安装并重启。
- 自动更新默认开启，可在控制台的“启动”区域关闭。
- 自动更新失败时保留当前可用版本，不弹窗打断；手动检测和升级入口继续保留。

## 提醒与专注修复

- 轻提醒只针对短期任务；只有长期任务时保持安静。
- 普通轻提醒弹窗最多展示 3 条短期任务。用户为单条任务明确设置的定时提醒不受影响。
- 修复今日专注任务数量与菜单栏显示可能长时间不同步的问题。

## 兼容性

本版本不改变待办、今日专注或现有设置的数据格式。兼容 macOS 14.0 及以上版本，普通升级不会清除用户数据。
