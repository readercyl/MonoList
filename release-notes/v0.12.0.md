# MonoList v0.12.0

本版本把 MonoList 收敛为更轻量的工作提醒清单：打开后直接看到当前待办，菜单栏浮窗和主窗口使用一致的任务顺序与层级。

## 主要更新

- 主窗口改为竖向轻量布局，设置直接内置在主窗口，不再打开独立设置窗口。
- 移除“今日专注”、短期任务和长期任务分类；前 3 条一级待办自动使用从大到小的字号，后续任务使用正常字号。
- 一级任务直接点击即可展开或收起二级任务，移除影响对齐的展开箭头；菜单栏浮窗保持相同交互。
- 编辑待办时点击空白区域即可结束编辑；菜单栏浮窗点击主页区域后会正常收起。
- 已完成任务按完成日期归类，主窗口默认展示当天记录；历史记录可按需显示或隐藏。
- 菜单栏浮窗默认完整展示未完成任务清单，并保留“已完成”入口；隐藏历史后窗口会随内容收缩。
- 轻提醒只提示第一条没有单独提醒的待办，提醒弹窗会根据内容调整大小并使用更醒目的排版。
- 提醒开关与提醒声音开关分开控制；提醒声音默认关闭，开启提醒后仍可单独决定是否播放声音。
- 主窗口滚动较长内容后提供回到顶部按钮，设置页在内容不足时保留轻微滚动回弹。

## 兼容性

- 支持 Apple 芯片 Mac（M1 或后续型号）。
- 支持 macOS 14.0 及以上版本。
- 继续兼容已有待办、完成记录和提醒设置；正常覆盖升级不会清除用户数据。
